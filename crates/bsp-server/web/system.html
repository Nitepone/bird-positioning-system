      Firmware

      Upload a build

      An ESP32 build's firmware.bin, from firmware/.pio/build/<board>/. Its hardware, version and build time are read from the image, so there is nothing to type; uploading the same image again changes nothing. Which build a device runs is chosen on its Firmware tab under Devices: devices set to a latest build move to a newer upload by themselves.
